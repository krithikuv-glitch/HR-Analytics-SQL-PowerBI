# HR Analytics Dashboard

HR Analytics project using SQL, Excel, and Power BI to analyze employee data and understand workforce trends.

## Tools Used

- SQL
- Excel
- Power BI

## Analysis

- Employee headcount
- Employee attrition
- Department-wise analysis
- Salary analysis
- Job role analysis
- Employee performance
- Hiring trends

## Dashboard

The Power BI dashboard provides an interactive view of HR metrics, employee details, and workforce trends.

## Project Files

- `HR_data.csv.xlsx` – HR dataset
- `HR-Data-Analysis-SQL.sql` – SQL analysis queries
- `Hr Analytics Dashboard.pbix` – Power BI dashboard
- Dashboard screenshots

## Key Skills

SQL | Excel | Power BI | Data Analysis | Data Visualization
