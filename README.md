# HR Analytics Dashboard

An HR analytics project using **SQL, Excel, and Power BI** to analyze employee data and understand workforce trends, salary patterns, employee performance, and attrition.

## 🎯 Project Objective

The goal of this project is to transform employee data into meaningful insights that can help HR teams understand their workforce, identify employee attrition patterns, analyze salary distribution, and monitor department and job-role performance.

## 🛠️ Tools & Technologies

- SQL
- Microsoft Excel
- Power BI

## 📊 Analysis Performed

- Employee headcount and workforce overview
- Employee attrition analysis
- Department-wise employee distribution
- Salary and compensation analysis
- Job role analysis
- Employee performance analysis
- Hiring and workforce trends

## 📈 Dashboard

The Power BI dashboard provides an interactive view of key HR metrics, employee details, and workforce trends.

Users can explore the data through interactive charts, filters, and KPIs to identify important patterns across departments, job roles, salaries, and employee status.

## 💡 Key Outcome

The analysis helps provide a clearer view of workforce composition and employee trends. It can support HR teams in identifying areas of high attrition, understanding salary distribution, comparing departments, and making more informed workforce decisions.
